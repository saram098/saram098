### About

I build production AI: multi-agent systems, real-time voice agents, RAG pipelines and the backends that run them. 4+ years shipping, currently **Head of AI Engineering at [The Botss](https://thebotss.com)**, where I lead architecture and hands-on build for 30+ clients across legal, healthcare, e-commerce and enterprise in the US, Europe, Australia, the GCC and Pakistan.

I care about the boring parts that make AI work in production: evals, cost, latency and reliability.

- Shipped **9+ production AI systems**, from voice agents to document AI
- Cut LLM inference cost **~58%** on a ~3,000-user agent (98.5% prompt cache hit rate + OpenAI/Gemini provider layer)
- Integrated Stripe, Shopify, GoHighLevel, Airtable, Google Calendar, WhatsApp, Messenger and Telegram into agent tool-calling workflows

| Project | What it does | Stack |
|---|---|---|
| **Arthur** | Multilingual (EN/DE/RU) AI agent with voice calling, event booking and Stripe payments, ~3,000 users. Broke a 6,000+ line prompt into layered sub-agents. | OpenAI Agents SDK, ElevenLabs, Twilio, Gemini, PostgreSQL |
| **Accident Assist AI** | AI legal intake app (App Store) that interviews US accident victims, builds case files via tool calling and routes leads to law firms. | OpenAI Agents SDK, FastAPI, PostgreSQL, AWS |

| **Commify AI** | Omnichannel shopping agent on WhatsApp, Instagram, Facebook and web (Shopify App Store). | OpenAI, WhatsApp Business API, Meta, Shopify |
